# Cyber Defender
Cyber Defender is a Scratch game created for CS50x Problem Set 0.
## How to Play 
- Use the left and right arrow keys to move the robot.
- Collect the falling data stars to increase your score. 
- Avoid the viruses because they reduce your lives.
- The game ends when no lives remain. 
## Concepts Used 
- Variables
- Loops
- Conditional statements
- Custom blocks 
- Keyboard input 
- Collision detection
## How to Run
Download the .sb3 file and open it using the Scratch editor
at: https://scratch.mit.edu/projects/editor/
